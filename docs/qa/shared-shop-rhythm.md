# T12 三店共享协议节奏报告

日期：2026-11-11。工具 `tools/shop_rhythm.gd`，当前协议基线 `tests/baselines/shared_shop_rhythm.json`。

## 条件与口径

三店均seed42、600模拟秒、所有既有工位开放、现有原料箱购买、恰好双员工。初始资金仅供固定测试布置，不购买培养或提速，使用正式配置的价格、工序和菜单需求。场景使用正式motion1/action1/flow0定义。所有计数来自真实ShopRules；角色仍按正式权限和脚底半径寻路。

每tick为0.1秒。销售事件与物品数分开：煎饼可一单含配餐，第三店可主菜带例汤。首单和销售间隔按销售事件计算；操作时间与移动时间是累计员工时间，两员工合计1200秒。明确blocked动作记为等待；调度器没有可接工作记为空闲，可能包含等待机器产物、配方前置和岗位限制，不能解释为“完全没有生产依赖等待”。

本报告是统一条件下的可重复诊断，不是新玩家从空店攒钱解锁的通关时长，也不是不同菜单收入的横向平衡目标。
