日期：2026-10-29。分支：`codex/shop-ui-foundation`，基于已合入 main 的 `ca9b330`。

本页记录基础 UI 框架阶段。后续已接入真实经营解锁、升级、员工收藏/派遣与存档，最新说明见 [tea-business.md](tea-business.md)。下文的“试玩上限”等描述是当时边界。

## 体验

F5 进入现有奶茶店试玩。顶部仅保留店名、金币、售出杯数、倍速和菜单；底部入口为店铺、建造、员工、招募。

- 员工：根据当前已拥有员工生成头像卡，点击查看等级、擅长类型、工作状态与属性；培养会支付真实金币、提升真实能力。
- 拖放：按住员工卡拖动后面板收起，松到煮茶台/加料台坐班，松到连通的空地恢复流动；点选场景员工可打开简短操作条，再进入详情。
- 招募：普通招募接入现有 35/60 金币的伙伴获得流程；人数达到当前试玩上限或余额不足时禁用。高级招募标为尚未开放。
- 建造：机器、传送带、布局分类均明确未开放，不会消耗金币或改动家具。
- 菜单：暂停/继续、人工或传送带运输、重新开始、旧版入口。重开有游戏内确认；取消保留当前金币、员工及暂停状态。
- 关闭、底部店铺入口、遮罩或 ESC 可退出面板。打开面板不会自动暂停或恢复营业。

顶部、导航、遮罩和弹层框架在 `presentation/tea_playtest/shop_hud.tscn` 中，可独立在 Godot 编辑器中调整；员工卡绑定现有模拟状态。横屏 UI 使用独立于场景的适配比例，弹层内容可滚动。

## 验证范围

- 完整模拟与资源回归：99 个用例、0 失败。
- `tests/render_shop_ui.gd`：实际鼠标事件验证页面切换、真实招募扣费、选中员工培养、菜单暂停、ESC 退出保留暂停、重开取消与确认、手机及横屏操作。
- 员工卡的隐藏、ScrollContainer 裁剪和弹层遮挡均参与命中检测；横屏滚到底后，标题区域不会拖起被裁剪员工卡。
- 拖拽的预览与提交均拒绝 HUD 区域；松到横屏顶部面板不会误改下方工位。
- `tests/render_staff_posts.gd`：原有真实鼠标和触摸拖拽、取消、多指、即时落位、携货退款、各种无效工位与三种窗口尺寸继续通过。
- `tests/render_tea_playtest.gd`：真实招募、培养、暂停、倍速、物流切换、重开以及旧版存档往返继续通过；所有隐藏操作先通过可见入口导航。
- UI 回归已接入 CI，无头运行可验证交互；桌面渲染运行额外保存截图。UI 回归收集运行时脚本错误并据此返回失败。
- 独立代码审查发现的两项 UI 命中问题已修复，并独立复验通过。

现有完整模拟回归仍带此前记录的退出 Canvas/ObjectDB/资源告警；三个实际 GUI 验证未出现运行中脚本错误。

## 本轮边界

本轮交付 UI 基础结构与现有功能迁入；没有新增机器建造、传送带布局、随机抽卡、稀有度、持久化员工收藏或试玩保存规则。当前员工面板展示当前试玩拥有并在店内工作的伙伴。
