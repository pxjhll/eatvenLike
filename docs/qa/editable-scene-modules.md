# T08 可编辑场景模块与空间导出验收

日期：2026-11-11。基于已推送的87cb87f（T07），本轮T08保留在工作区，不自动提交或推送。

## 交付内容

新增station、counter、table、entrance_queue、space五类可编辑灰盒预制体和ShopTemplate。模块根负责本地坐标，Visual可替换美术；本地Anchors/Nav定义交互、显示、操作/取餐/座位接近点、脚底占地和权限区域。工位ID、座位组与索引显式绑定已有数据，不按店铺ID分支。

ShopAnchors提供只读模块投影，沿用原Stations、Drops、Seats、Tables、Queue等接口；没有生成第二份锚点。移动实例后同一读取器的点和矩形坐标随动，不缓存旧队列位置。坐姿显示与实际抵达端口分离。桌椅容量通过seats_per_table传给现有餐盘显示，支持三座变体；容量、首座号与桌号不一致时拒绝。

module_version=1开启完整空间导出；旧场景仍走原Nav分支。完整比较包括导航、格子、区域、占地/解锁引用、员工点/岗位、别名、出生点、运动版本/密度、角色权限、顾客端口和队列。区域必须整格对齐；脚底半径与逻辑密度复用T05。所有占地激活后，员工从出生点到端口、顾客从入口到端口和队列必须可达。无路、占地内端口、区域越界、重复所有者、错误引用、非有限值、旋转/缩放和未知版本都不会静默导出。

sync_shop_layouts新增显式--shop/--campaign入口。--check发现差异非零退出且原字节不变；所有候选先校验，任一已知错误阻止整个批次写入。非场景资源、无Nav场景的密度错误、空目标和未知参数也会失败。实际磁盘保存仍逐文件报告，不提供多文件事务恢复。

工位Visual沿用已有解锁规则。灰盒桌子预先存在，椅子随已购座位显示；桌椅整套占地始终预留。表现通过ShopView.seat_count查询座位数，不访问运行容器。该方法返回标量；刷新和快照不会改变规则。

## 适用范围与下一步

本轮是编辑模块、灰盒样板与公共导出能力，没有替换正式店美术、PNG、shop.tres、员工数值或经济配置。旧店未声明module_version就不启用模块导出；奶茶冻结轨迹继续由全量规则回归验证。

导出是制作阶段操作，不是运行中移动家具或给任意旧档坐标重新定位的系统。检查所有占地打开的几何，避免后续建成后堵路；不提供人与人之间的物理避让。模块未根据图片自动推断占地，仍由制作人员在编辑器中核对。
