## 欢迎页前置加载层补充验收

- 原欢迎图在 Godot 引擎/PCK 加载前由 HTML 显示，进度区覆盖图中按钮。进度来自引擎与独立 MP4 的实际字节回调；引擎完成初始化且视频缓存准备结束后，才揭示原有游戏按钮。
- 隔离 Chrome、390×844、要求真实用户手势的自动播放策略下，延迟 MP4 下载直至游戏准备完成：Enter 无法提前播放，视频下载结束后也不自动播放；点击原图按钮后首次播放一次，AudioContext 为 running。
- 点击后的视频使用预加载 Blob URL；同一轮流程只有一次 MP4 下载请求。播放结束释放视频和 Blob，保持末帧，再点击进入原存档对应店铺。
- 引擎/PCK 请求返回 503 时显示刷新按钮；新增实际键盘测试复现并修复了 Enter 被加载门禁误拦截的问题，Enter 可触发刷新。
- MP4 请求返回 503 时仍可进入末帧回退并开始营业。
- 启动、音频、导出准备回归通过；导出准备包含正常复制与未知模板拒绝两个测试。实际 Web PCK 通过大小和场景一致性检查；JS 语法检查通过。
- 独立审查仅发现上述键盘重试问题，已修复并重测。浏览器自动化日志与截图位于 `_work/loading_flow_20261116/`。
