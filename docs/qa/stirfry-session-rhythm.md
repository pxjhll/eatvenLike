## 验收重点

1. 用1倍速从开局体验：前台接单后，米饭与炒菜分别准备，不再由一个厨师串行包办所有搬运。前台有本职任务时优先处理，有空才协助搬料；厨师仍负责炒制和装盘。
2. 观察第一份盖饭之后的连续出单：已炒好的菜优先完成；物料在运来途中，厨师可到工位等几秒，实际物料到齐才开始操作。候料中召回搬运员工，应能恢复补料，不锁死工位。
3. 观察新增菜单、增员与设备升级：一前台两后厨能比双人更连续出单；基础电饭柜每分钟4份米饭是后期产能限制，需要正常升级。全菜单基础设备压力场景仍可能排队流失，不声称已经无拥堵。
4. 检查人物正常走路、无穿家具或瞬移，搬运餐品只显示实际持有物。装盘台保持空桌面，运行中的米饭、熟菜和盖饭摆在台面上。
