# UI 美术清单（线框第一版）

日期：2026-10-29。对应线框 v1 的 Godot 实现。现在这些位置都用代码画的色块、圆角框或参考图临时顶替，美术到位后按文件名替换即可，布局不用改。

## 通用规则

- 设计画布 720×1280（竖屏）。下表“显示尺寸”是画布上的像素，**交付请画 2 倍**（表中“交付尺寸”），透明底 PNG。
- 可拉伸的框（按钮、卡片、气泡、进度条）做成九宫格：四角圆角留在“切边”范围内，中间部分纯色或可平铺，程序会拉伸中间。
- 色调沿用现有界面：底色 `#fffaf0`，卡片描边 `#e6d8bf`，正文 `#583e2d`，强调棕 `#8b6446`，金色 `#e6b94f`，完成绿 `#4f8a3a`。
- 文件放 `art/ui/`，命名用英文小写下划线，例如 `coin.png`。

## 不需要单独出图的

- 收入飘字“+N”、各处文字：用现有字体，程序上色加描边。
- 遮罩、弹层阴影：程序生成。
- 员工头像：沿用现有角色参考图。

## 建议顺序

先出 P0 三样（金币、6 个饮品小图标、订单气泡），这三样对“看得懂顾客要什么、赚了多少”影响最大；P1 是整体质感，可以一次出一套；P2 最后补。
