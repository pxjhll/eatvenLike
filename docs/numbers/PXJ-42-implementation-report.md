# PXJ-42 奶茶店实现记录

状态：实现中；数值均为可玩验证占位，不是最终经济方案。

## 最小契约与状态归属

原生 Godot 4.7/GDScript，沿用唯一 App autoload 和 GameSim 中介。ShopProgress 的 stage_index 是后厨权限唯一真值；ShopConfig.kitchen_unlock_stage 默认 0 保留面包店行为，奶茶店设为 1。UI 读复制快照并提交命令，不保存金币、库存或权限副本。未开放时厨房工序和物流不推进；前厅柠檬水生产继续。生产改造和厨房调岗在命令验证时拒绝，不扣费。解锁购买是特例，通过既有下一阶段营业额/金币/机位状态验证后一次提交，进菜单同时打开后厨。

老存档仍按原 index 0 对应 bakery；tea 追加在目录，只有新建 Profile 按 starting_shop_id 选择 tea。权限由已持久化阶段恢复，无第二个持久化布尔值。

## 原型参数

全部在 content/tea/tea.tres：柠檬水售价 12、奶茶售价 24；初始金币 80；累计营业额 120 后花 60 解锁锅及奶茶。柠檬原液每 3s 一份，调配 3s 一杯。生珍珠和奶茶基底每 1s 到货；锅 COOP 装/取各 0.6s、煮 18s、每锅两份熟珍珠，第二锅 100 金币；熟珍珠+奶茶基底 1s 调配一杯。两饮料共享前厅 7s 封口/服务人工工序，沿用员工效率/工作区调岗和 2s 步行。起始来客 4s、双菜单 1.5s，±15%；队列 6、耐心 24s、各成品库存 12。任务柠檬水 10 杯、奶茶 20 杯。质量、魅力、材料成本和宏观经济未定稿，不额外编造结论。
