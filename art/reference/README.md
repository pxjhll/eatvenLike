# 当前店铺美术

本目录保存游戏正在使用的独立透明 PNG，以及裁剪、摆放来源记录 `manifest.json`。

`presentation/reference/shop_art.tscn` 是当前店铺的可编辑分层场景。墙体、门楣、设备、家具、角色和饮品采用地面接触点进行 Y 排序；附属物随父家具一起移动或隐藏。修改素材时保留画布、透明区域和锚点，避免改变现有遮挡关系。

这些图素基于用户在 2026-10-27 提供的参考图拆分；遮挡部分由内置 imagegen 补绘。原始参考图、生图整图、提示词、PSD 和历史重建工具已移到仓库外归档，路径和恢复方式见 `docs/cleanup-2026-11-01.md`。未使用的机器变体和独立静态对照预览也已归档。

当前游戏直接使用本目录的成品 PNG，不依赖归档中的源图。原有纹理尺寸和场景几何审计保留在 `tests/fixtures/reference_texture_budget.json`；独立图素的裁剪和摆放元数据保留在本目录的 `manifest.json`。
