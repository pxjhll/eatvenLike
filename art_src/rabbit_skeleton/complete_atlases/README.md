# Complete part artwork

`front_right.png` is the exact user-approved complete-parts image supplied on 2026-10-30, copied unchanged from the attachment. The remaining four views are generated with built-in imagegen using the corresponding current walking frame for identity/view and the approved sheet for completeness/style. Full prompts are in `prompts.json`.

Each atlas has nine complete components: head, far ear, near ear, torso, far arm, near arm, far foot, near foot, tail. Components include closed contours and hidden shoulder/ear-root/ankle areas. Runtime assets are exported from these atlas components; never partitioned from the assembled character frames. Complete heads retain their original faces; no rectangular eye/mouth crops are used on these assets.
